# 播放器支持

BrimDeck 的音乐页和收起形态会显示正在播放的歌曲，并提供播放控制。歌名放得下时静止显示，放不下时（律动条越长，留给歌名的位置越窄）自动滚动播放，与收起形态一致；关闭动画后不滚动，鼠标悬停可看到完整歌名。不同播放器能提供的信息和控制不同：

| 播放器 | 显示 | 控制 |
| --- | --- | --- |
| 网易云音乐 | 曲目、封面、进度 | 开启 SMTC 后：播放、暂停、切歌 |
| QQ 音乐 | 曲目、进度 | 播放、暂停、切歌、拖动进度 |
| Apple Music | 曲目、封面、进度 | 播放、暂停、切歌<br>开启完整控制后：还可拖动进度、开关随机播放、切换重复模式 |
| 酷狗音乐 | 曲目、封面 | 播放、暂停、切歌 |
| 其他播放器 | 播放器提供给 Windows 系统媒体控制的曲目、封面与进度 | 播放器支持的播放、暂停、切歌、拖动进度 |

"其他播放器"指接入 Windows 系统媒体控制的播放器，即播放时会出现在 Windows 音量浮窗媒体卡片中的播放器。

## 网易云音乐

- 默认读取本机播放记录，显示曲目、封面和估算进度。
- 在网易云“设置 › 系统”开启 SMTC 后，可以播放、暂停和切歌。
- 此 fork 禁用启动调试模式和写入新的 DLL 补丁。旧补丁可在“设置 › 播放器”关闭“旧版调试补丁”，之后完全退出并重新启动网易云。详见[数据与隐私](privacy.md#网易云音乐完整控制)。

## Apple Music

- **默认**：显示曲目、封面和进度，可以播放、暂停和切歌。
- **完整控制**：在音乐页点击"启用完整控制"并确认后，可以拖动进度、开关随机播放、切换重复模式（关闭、全部重复、单曲重复）。这些功能通过 Windows 的界面自动化操作 Apple Music 窗口中的按钮和进度条实现，因此需要 Apple Music 的主窗口存在；主窗口没有最小化时，使用这些功能会把它带到最前面。完整控制在 BrimDeck 重启前有效；在"设置 › 播放器 › Apple Music"中打开"始终启用完整控制"后，BrimDeck 每次启动都会自动启用。

## 酷狗音乐

- 在酷狗“设置 › 常规设置 › 播放”勾选“支持系统播放控件，如锁屏界面”，可显示曲目、封面并控制播放、暂停和切歌。
- 此 fork 不再安装 DLL 调试补丁，酷狗未通过系统媒体控制提供的实际进度不再由本 fork 开启调试端口获取。
- 旧补丁可在“设置 › 播放器”关闭“旧版调试补丁”，再完全退出并重新启动酷狗；受保护目录可能需要管理员确认。详见[数据与隐私](privacy.md#酷狗音乐完整控制)。

## 多个播放器与忽略的应用

- 同时有多个播放器在播放或暂停时，可以在音乐页右上角的来源菜单中切换，或固定显示其中一个。
- 不想显示的应用可以加入"设置 › 播放器 › 播放来源 › 忽略的应用"。被忽略的应用播放时，面板不显示它的歌曲，来源菜单中也不列出它。忽略浏览器会忽略其中所有网页的播放。

## 快捷操作

在音乐页上按住鼠标向左、右、上、下拖动，或用触控板双指左右滑动，可以执行上一首、下一首、切换播放器、播放或暂停、调节音量。每个方向对应的操作在"设置 › 快捷操作"中选择。

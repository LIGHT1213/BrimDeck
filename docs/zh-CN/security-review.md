## 额外发现及修复

- 免安装更新遇到文件/目录结构变化后失败时，回滚可能无法恢复旧文件，接着删除唯一备份。已修复恢复顺序和目录转换；无法完全恢复时保留备份，以后的更新也不清除这些恢复文件。
- 只有 beta、没有正式版，或正式版清单损坏时，旧代码不会继续检查健康的 beta 源。两个源现独立检查，保留调用方取消和服务端限流信息。
- fork 的更新源、传感器下载和主页原先指向上游。现由构建写入当前仓库，避免安装上游版本覆盖 fork 修复。
- 增加 `build-windows.yml`，生成自包含安装程序和免安装包。Actions 构建附带传感器程序，同时保留编译时的 SHA-256 校验。

## 使用与残余风险

- 本 fork 不再主动打开播放器调试端口。先前安装或其他软件已经打开的端口不会因安装本 fork 自动关闭。对旧补丁，请在“设置 › 播放器”关闭“旧版调试补丁”，然后完全退出并重新启动播放器；此操作可能需要管理员确认。
- 剪贴板加密仍依赖当前 Windows 用户的 DPAPI；已在该用户权限下运行的恶意软件不在其防护范围内。拖出图片时，接收方仍需要明文文件。崩溃后的文件会在下次启动清理，不能保证程序未再次启动时文件立即消失，也不承诺安全擦除。
- 同源限制保护的是脚本的网络目的地。用户仍应信任自己配置的站点；站点本身会接收它的 API Key。
- 更新签名不能防止本机恶意软件替换整个应用，也不能抵御构建环境与签名私钥同时失陷。公钥必须随可信构建分发；私钥不应进入仓库。可离线签名，或在受审批保护的 `release` 环境中使用独立私钥。
- 没有对 418 个 C# 文件逐行审计，也未运行上游发布的 EXE；本报告不是“仓库绝无后门”或发布二进制与源码一致的证明。
